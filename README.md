# blocksworld

## Overview

A Blocksworld problem solver developed as part of the course Aide à la décision artificielle.
This project explores different approaches to problem solving, including graph search algorithms, constraint satisfaction, and data mining techniques.

## Features
- A*, BFS, DFS, Dijkstra
- CSP modeling
- Data mining (Apriori, etc.)

## Objectives
- Compare the efficiency of different search strategies
- Model the Blocksworld problem using CSP techniques
- Extract patterns from generated states using data mining
